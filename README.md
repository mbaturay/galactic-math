# Galactic Math

Galactic Math is a SpriteKit arcade game that blends classic space action with adaptive math practice. Players pilot a ship, solve math problems, and clear waves of enemies across themed sectors.

## Features
- Adaptive difficulty that reacts to player performance
- Multiple math topics and age groups
- Progressive waves with increasing challenge
- Audio, effects, and score tracking

## Requirements
- macOS with Xcode installed
- Swift and SpriteKit (bundled with Xcode)

## Getting Started
1. Open `GalacticMath.xcodeproj` in Xcode.
2. Select a macOS or iOS simulator target as appropriate.
3. Build and run.

## Project Structure
- `GalacticMath/` - Source code and assets
- `Scenes/` - Game flow scenes
- `Nodes/` - SpriteKit nodes and effects
- `Systems/` - Game systems (difficulty, math, waves)
- `UI/` - HUD and interactive overlays
- `Space Pack/` - Game Assets
